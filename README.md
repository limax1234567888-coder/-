# 进宅请帖 · H5 单页

文件：index.html（页面）+ music.wav（背景音乐）。两者放在同一目录即可，双击 index.html 就能打开。

## 1. 怎么打开

- 电脑：双击 index.html
- 手机：把 index.html 和 music.wav 一起发到微信「文件传输助手」，用手机浏览器打开其中的 index.html；
- 想要链接：把这两个文件一起传到 Netlify Drop / Vercel / GitHub Pages / OSS / COS，访问 index.html 即可。

## 2. 改内容

### A. 直接点着改（推荐）

打开 index.html?edit=1，右下角出现面板：所有文字都能直接改，点「保存到本机」；点「导出配置文件」可拿到最终配置。

### B. 改代码

搜索 window.INVITE_CONFIG，常用字段：

```js
window.INVITE_CONFIG = {
  title:        "进宅大吉",
  subtitle:     "乔迁之喜　新居落成",
  dateText:     "2026.11.08",
  timeText:     "星期日 · 中午十二时 入席",
  dateISO:      "2026-11-08T12:00:00+08:00",  // 倒数用
  addressTitle: "云栖里 三号楼一单元 1802 室",
  mapKeyword:   "云栖里三号楼一单元1802",
  lat: "", lng: "",                             // 高德坐标，填了就精准定位
  phone:        "13800000000",
  photo:        "",                             // 封面照片
  music:        "music.wav",                    // 背景音乐
  musicVolume:  0.45,
  autoScroll:       true,                       // 自动向下滑
  autoScrollSpeed:  20,                         // 每秒像素，越小越慢
  autoScrollDelay:  3200,                       // 打开后多久开始（毫秒）
  autoScrollResume: 6500                        // 手动滑动后停多久再继续
};
```

## 3. 背景音乐（默认开启）

- 打开页面就尝试播放，**默认是开的**，不需要手动点；
- 桌面浏览器一般直接出声；
- 手机浏览器限制自动播放，采用「静音自动播放 + 首次轻触出声」：点一下、滑一下，声音立刻出来，不会从头重播；
- 右下角圆钮：响着时点一下是暂停，暂停后再点是继续；
- 不再记忆上次的开关状态，每次打开都默认开启；
- 换音乐：把 mp3/wav 放到与 index.html 同目录，改 music: "your.mp3"；
- 不要音乐：music: ""（按钮会自动隐藏）。

## 4. 导航按钮

点「导航前往」会从底部弹出选择：**高德 / 腾讯 / 百度 / Apple 地图**。

- 手机：直接唤起对应 App（没装则打开该地图的网页版），用系统返回键回请帖；
- 电脑：新标签页打开网页地图；
- 想让某个地图**默认直接跳、不弹选择**：把 mapProvider 改成 "amap" / "tencent" / "baidu" / "apple"；
- 定位优先级：填了 lat / lng 就按坐标落点（高德、腾讯、Apple 用 GCJ-02；百度用 BD-09，坐标不换算的话百度可能偏几十米，建议不填坐标、用地址搜索）；
- 没填坐标时按 mapKeyword 搜索，所以**只填地址也能用**；
- 地图上显示的地名在 mapName 里改。

上传到任何静态托管后行为一致：纯前端跳转，不需要后端。

## 5. 自动下滑

- 打开 3.2 秒后开始缓慢向下滚（默认 20px/秒），像自动放映；
- 有任何触摸 / 滚轮 / 按键操作，就暂停 6.5 秒再继续，不跟用户抢；
- 左下角圆形按钮可随时开关：播放中是「❚❚」，暂停时是「▶」；到页面底部自动停下；
- 系统开启「减少动态效果」时自动关闭，按钮也会隐藏；
- 想彻底关掉：autoScroll: false；想更快：把 autoScrollSpeed 调大（如 40）。

## 6. 配色（深红 + 烫金）

主色在 :root 里，改这四个就换掉整张请帖的底色：

    --red-0:#b0342c;   /* 顶部暖光 */
    --red-1:#8e1717;   /* 主色 · 深红 */
    --red-2:#7a1013;   /* 中段 */
    --red-3:#580a0c;   /* 底部最深 */

金色与文字：--gold-1~4、--cream / --cream-2 / --cream-3。
背景渐变在 .bg 里，封面照片遮罩在 .cover.has-photo::before 里，跟着一起换就统一了。

## 7. 连续长卷 / 整体金框

- 整页只有**一层固定背景**（红色渐变 + 噪点），滚动时背景不动；
- **金框跟着内容滚动**：它包在 `.sheet` 里，从页面最顶端一直画到最底端，四角角饰分别在整张请帖的四个角；
- 只有封面占满首屏，正文和信息页顺次往下流，段与段之间靠留白和金线分隔；
- 每个区块顶部有一层柔和金晕，和封面同源。

### 屏幕适配

- `.sheet` 最宽 940px，桌面居中，不会拉成一条超宽横幅；
- 金框内缩 `clamp(10px, 2.4vw, 22px)`，窄屏 10px、宽屏 22px，自动跟着屏幕走；
- 内容左右留白 `clamp(28px, 7.4vw, 46px)`，始终比金框靠内，不会压线；
- 字号全部 `clamp()` 连续缩放（320px ~ 1920px 都不会溢出）；
- 短屏（高度 ≤640px）自动隐藏灯笼、缩小印章，横屏也不挤。

## 8. 首页装饰

封面新增：两盏轻微摆动的红灯笼、标题后的金色光晕（缓慢呼吸）、10 个闪烁金点、底部云水纹带、四角金线角饰。
全部是 CSS/内联 SVG，没有额外图片；灯笼、光点位置都可用 CSS 变量微调。

## 9. 其它细节

- 响应式：clamp() 流体字号，手机优先；桌面金框收窄到 780px 居中；
- 倒数到点自动变「吉日已至 · 恭候光临」；
- 「导航前往」优先用 lat/lng，否则按地址搜高德；「复制地址」兼容老浏览器；
- 支持 prefers-reduced-motion、iPhone 安全区、noscript 兜底。
